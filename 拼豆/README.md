# 拼豆工坊 · Perler Studio

把任意一张图片变成可以照着拼的**拼豆图纸**：

```
图片 ──▶ 面积平均像素化 ──▶ 主色量化（中位切分 + k-means）
     ──▶ 相近色合并（CIEDE2000）──▶ 吸附到拼豆色卡 ──▶ 编号图纸 + 用量表
```

纯前端、零依赖、无需联网：图片只在本地浏览器里处理，不会上传。

---

## 快速开始

- **直接双击 `index.html`** 即可（Chrome / Edge / Firefox 都行）。
- 如果浏览器因为 `file://` 安全策略拒绝读取像素，在本目录跑一个本地服务器：

  ```powershell
  python -m http.server 8000
  # 然后打开 http://localhost:8000/
  ```

  或 `npx serve .`。

打开后点「示例图」可以先看效果，再导入自己的图片。

## 功能

### 1. 像素化（决定图纸颗粒感）
- **横向豆数** 8–200，可锁定原图比例，也可手动指定纵向豆数。
  每个数值都配了「滑块 + 数字框」：拖滑块看效果，点数字框直接敲（回车或失焦生效，超范围自动夹到边界）。
- 降采样用**面积平均**而不是丢点采样，缩到很小的格子数时颜色也更稳。
- 快捷键：29 / 58 / 87 / 116（5 mm 豆下 29 颗 ≈ 14.5 cm，正好一块标准拼豆板）。
- 豆子规格可选 2.6 mm / 5 mm / 10 mm，概览里直接显示成品厘米数。

### 2. 配色（决定像不像、好不好买豆）
- **最多颜色数**：中位切分给出初值，再在 Lab 空间用 k-means 精修。
- **相近色合并（ΔE2000）**：把色差小于阈值的豆色合并成一种，豆量少的并入豆量多的。
  `0` = 不合并；`3~6` 比较温和；`10+` 会明显减少颜色但细节变少。
- **抖动**：关闭（推荐）/ 弱 / 强。强抖动会用混色模拟渐变，但豆面会「沙沙的」。
- **透明区域**：白底 / 黑底 / 留空（不排豆，空格不进统计）。
- **亮度 / 对比度 / 饱和度**：转换前微调，适合补救偏暗的照片。

### 3. 色卡（决定能不能真的买到豆）
内置 3 套屏幕参考色卡：**通用 84 色**、**新手 48 色**、**柔和马卡龙 36 色**。

> ⚠️ 内置 HEX 是屏幕近似值，不同批次/显示器有色差，下单前请对照实体色卡。
> 买的是别的品牌，就用「导入」把自己那套色卡塞进来，之后所有映射都基于它。

### 4. 图纸与导出
- 预览三种样式：彩色豆 / 白底图纸（省墨）/ 彩色 + 编号；数字或符号编号；网格、每 5 格加粗、拼豆板分界线、坐标刻度。
- 鼠标悬停显示坐标 + 色号 + HEX；点右侧色号表可高亮某一种颜色的所有格子。
- **导出图纸 PNG**，四种样式：

  | 样式 | 内容 |
  |---|---|
  | **数字表（默认）** | 白底 + 细网格 + 黑色外框，每格一个编号；**图片最下方列出每种编号（颜色）的颗数** |
  | 白底图纸 | 带坐标刻度、标题、每 5 格加粗线，末尾配色表（色号 / 名称 / 用量） |
  | 彩色底 | 直接看颜色块 |
  | 彩色底 + 编号 | 颜色块 + 编号 |

  - 勾「按拼豆板分页」后可再选**多页拼接**：
    - **按原图位置拼成一张**（默认）：4 页就拼回 2×2 一张图，每块自带黑框，正好当拼豆板分界；
    - 一页接一页竖排：适合逐页打印。
  - 其余选项：格子编号（数字 / 符号 / 不显示）、每 5 格加粗辅助线、每页格数、是否附用量表。
  - 分页时用量表自动附在最后一页；打印始终按页输出。
- **打印**：按页输出，直接进浏览器打印对话框。
- **配色 CSV**：色号 / 名称 / HEX / RGB / 数量 / 占比，带 BOM，Excel 直接打开不乱码。
- **项目 JSON**：连原图带参数一起存，下次「载入项目」继续改。

所有设置自动存在浏览器 localStorage，下次打开还是上次的参数。

## 导入自己的色卡

点配色区的「导入」，粘贴 JSON 或 CSV：

**CSV**（每行 `色号,名称,#HEX`，表头可有可无）
```csv
A1,纯白,#FFFFFF
A2,米白,#F6F1E4
B1,正红,#E4352E
```

**JSON**
```json
[
  { "code": "A1", "name": "纯白", "hex": "#FFFFFF" },
  { "code": "A2", "name": "米白", "hex": "#F6F1E4" }
]
```

也可以直接选文件（`.json` / `.csv` / `.txt`）。导入的色卡存在本机，可以随时「清除已导入」。


产出三样东西：

| 产物 | 用途 |
|---|---|
| `dist/拼豆工坊.html` | **单文件版**（约 130 KB）。微信/邮件直接发，对方双击用 Chrome / Edge 打开即可，无需安装、无需联网（除首次打开）。 |
| `dist/site/` | 静态站点（index.html + css/ + js/）。拖到 Netlify Drop、Cloudflare Pages 或 GitHub Pages，就能得到一个链接，手机也能开。 |

> 如果对方用 Safari 打开后提示读不到像素，改用链接版（`dist/site` 托管）即可。

## 算法说明（为什么这么做）

1. **面积平均降采样**：每个格子覆盖的源像素按面积加权平均，避免细线、噪点在缩小时被「漏掉」。
2. **加权中位切分**：按「豆量 × 色域跨度」挑最该切开的盒子，沿 Lab 跨度最大的轴切；先粗分。
3. **k-means 精修**：在 Lab 空间迭代，聚类中心用豆量加权 —— 大面积的颜色更稳，小细节不被拉偏。
4. **吸附色卡**：把每个主色按 CIE76 距离换成最近的拼豆色号（真正能买的颜色）。
5. **相近色合并**：反复找当前色差最小的一对，若「超过颜色数上限」或「ΔE2000 < 阈值」就合并，
   小豆量并入大豆量，直到满足条件 —— 这就是「把部分相似颜色转换掉」。
6. **重新分配**：所有格子用最终色卡再按最近色分配（可选 Floyd–Steinberg 蛇形抖动），
   统计用量、按豆量重新编号（1 号 = 用得最多的豆），保证图纸和色号表完全一致。

## 已知限制 / 下一步

- 内置色卡是屏幕参考值，非品牌官方数据；建议导入自己买的色卡。
- 没有做「孤点清理」「最大连通区域优化」，极小的高光/噪点偶尔会留下一两颗单豆。
- 还没做：局部框选重算、一键替换某色、按颜色分文件导出（每种颜色的坐标清单）、
  AI 超分预处理、多图纸拼版。
